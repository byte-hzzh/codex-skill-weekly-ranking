How it works

Methodology & limitations

Formal weeks use two Monday boundary snapshots. Repository gains are allocated among eligible Skills using Laplace-smoothed path commits, normalized to percentiles, and scored as 65% stars, 15% forks, and 20% commits. Trial weeks use cumulative public totals and recent path activity under a separately versioned formula.

  • Stars and forks are repository aggregate snapshots, not Skill installs.
  • Path commit counts measure default-branch history touching the Skill path, not effort.
  • GitHub does not provide this project with exact public stargazer event times.
  • This trial ranking uses current cumulative repository totals because a full week is unavailable.
  • No new valid ranking was produced; this view preserves the last successful ranking and its original observation times.
